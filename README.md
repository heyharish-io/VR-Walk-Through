# VR Walk Through

A Unity-based Virtual Reality walkthrough project designed to explore and navigate a 3D environment using VR controls.

## Overview

VR Walk Through is an interactive virtual environment created in Unity. The project focuses on VR movement, environment exploration, and basic teleportation-based navigation.

## Features

- VR environment walkthrough
- First-person VR exploration
- Smooth movement
- Teleportation navigation
- VR controller input
- Interactive 3D environment
- Unity XR workflow
- Android/VR-ready project structure

## Technologies

- Unity
- C#
- XR Interaction Toolkit
- Unity Input System
- Universal Render Pipeline
- Git
- Git LFS
