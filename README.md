# VR Walkthrough

A Unity-based Virtual Reality (VR) project designed to explore a 3D environment using XR interaction systems.

## Overview

VR Walkthrough is a VR environment developed using Unity and the XR Interaction Toolkit. The project focuses on VR scene setup, controller configuration, locomotion systems, and immersive environment exploration. It was tested using the XR Device Simulator during development.

## Features

- 3D virtual environment exploration
- XR Origin and VR camera setup
- VR controller and interaction configuration
- Locomotion and teleportation system setup
- Unity XR workflow
- OpenXR configuration for Meta Quest compatibility
- Android build configuration

*Note: Controller movement and teleportation are still being refined. The project was tested using the XR Device Simulator, not a physical VR headset.*

## Technologies

- Unity 6
- C#
- XR Interaction Toolkit
- Unity Input System
- OpenXR
- Meta XR SDK
- Universal Render Pipeline (URP)
- Git and Git LFS
